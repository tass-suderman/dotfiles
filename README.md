# Dotfiles
My Arch Linux dotfiles. Inspired from various sources and always a work in progress.

<img title="Arch Linux Hyprland" alt="Arch Linux Hyprland" src="/images/dotfiles.png" />

## Current Packages
- Window Manager - [Hyprland](https://github.com/hyprwm/Hyprland)
- Status Bar - [Waybar](https://github.com/Alexays/Waybar)
- Launcher - [Rofi](https://github.com/davatorium/rofi)
- Terminal - [Alacritty](https://github.com/alacritty/alacritty)
- Music Player - [Feishin](https://github.com/jeffvli/feishin)
- Chat Client - [Element](https://github.com/element-hq/)

## Previous Packages
- Window Manager - [i3](https://github.com/i3/i3)
- Status Bar - [Polybar](https://github.com/polybar/polybar)
- Compositor - [Picom](https://github.com/yshui/picom)
